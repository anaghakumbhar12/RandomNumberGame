# 🎯 Random Number Guessing Game

A simple and interactive number guessing game built with **HTML, CSS, and JavaScript**. Players guess a randomly generated number with hints, attempt tracking, a timer, and a restart option.

## 🚀 Features

* Random number generation
* High/Low hints
* Attempt counter
* Timer
* Restart game
* Responsive design

## 🛠️ Technologies

* HTML
* CSS
* JavaScript

## ▶️ Run Locally

```bash
git clone https://github.com/your-username/random-number-game.git
```

Open `index.html` in your browser.
